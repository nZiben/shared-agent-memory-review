# Общая память агентов

[Открыть обзор](https://nziben.github.io/shared-agent-memory-review/)

Как агентам делиться опытом, не распространяя ошибки?

50 публикаций: подходы, результаты, ограничения, цитаты и ссылки на конкретные разделы. На сайте есть краткий ответ, подробное сравнение, источники и история выпусков. Это выборочный разбор, не исчерпывающая рецензия; эксперименты не воспроизводились.

```sh
python3 -m unittest discover -s tests -q
python3 -m review_forge build-site --library library --destination public
python3 -m http.server 8877 --directory public
```

Python 3.11+, без обязательных внешних зависимостей. По понедельникам GitHub Actions ищет новые arXiv-кандидаты только по этой теме. Выводы автоматически не переписываются. Для обновления текста измените `reviews/shared-memory.json`, сохраните прежний выпуск в `reviews/history/shared-memory/`, укажите новый `snapshot_id` и пересоберите сайт.

Проект работает самостоятельно: не загружает код или данные из другого репозитория.
